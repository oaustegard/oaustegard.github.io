Agent Log

Agent Log records what a web page does (console output, errors, network calls) in your own browser, then exports it as an OpenTelemetry log file that you hand to Claude or another agent to debug the page.

An agent that writes a web page cannot watch it run in your browser. One script records the page there, in this browser's IndexedDB, with no server involved; a red Logging badge shows while it records, and the badge's panel downloads or copies the log. Nothing is sent anywhere.

The script does nothing until the page is opened with ?logging=true. After that, logging stays on in that tab, across reloads, until you press Stop logging or open a URL with ?logging=false. A page that should always log adds a data-start attribute to the script tag. The script is also served from GitHub through jsDelivr at https://cdn.jsdelivr.net/gh/oaustegard/oaustegard.github.io@main/web-utilities/agent-log.js, which caches branch files and can lag the site. A <script> tag cannot load it from raw.githubusercontent.com, because GitHub serves raw files as text/plain with nosniff.

Recorded events

Each record is an OpenTelemetry log record. Its eventName says where it came from:

eventNameRecorded whenSeverity
console.log, .info, .debug, .warn, .error, .trace, .assertthe page calls the console method (assert only when it fails)DEBUG to ERROR, by method
error.uncaughtan exception reaches windowERROR
error.rejectiona promise rejects with no handlerERROR
error.resourcean image, script or stylesheet fails to loadERROR
csp.violationthe page's CSP blocks somethingWARN
http.fetch, http.xhra request finishes or fails: method, URL, status, durationINFO; WARN at 400 and up; ERROR when it fails
page.navigation, page.visibilityin-page navigation; the tab is hidden or shownINFO
agentlog.start, agentlog.stoplogging starts or stopsINFO

Objects passed to the console become attributes, so a structured call is the cheapest way to get state into the log:

console.log("bot tick", { tic, pos: { x, y }, sector, target: t.kind, action });

That record has the body bot tick and the attributes tic, pos, sector, target and action. Strings and numbers in the call form the body; errors become exception.type, exception.message and exception.stacktrace; arrays, maps and DOM nodes become arg0, arg1 and so on. Values are copied when they are logged, nested four levels deep at most, with long strings and long arrays cut short.

The export format

Download and Copy produce an OTLP/JSON ExportLogsServiceRequest, the format an OpenTelemetry collector accepts at /v1/logs. Every page load is one resourceLogs entry; its resource attributes hold the page URL, title, user agent, viewport and a session.id:

{"resourceLogs": [{
  "resource": {"attributes": [{"key": "service.name", "value": {"stringValue": "austegard.com"}}, …]},
  "scopeLogs": [{"scope": {"name": "agent-log", "version": "1.0.0"}, "logRecords": [
    {"timeUnixNano": "1763164800123456000", "severityNumber": 9, "severityText": "INFO",
     "eventName": "console.log", "body": {"stringValue": "bot tick"},
     "attributes": [{"key": "tic", "value": {"intValue": "412"}}, …]}
  ]}]
}]}

Integers are strings and timestamps are nanoseconds, as the OTLP/JSON encoding requires. The skill below has a short Python reader that flattens the file into one line per record and filters it.

The skill for agents

The capturing-browser-logs skill tells an agent how to have you turn logging on, how to read and filter the export, and how to add structured console.log calls to code it is debugging. Paste it into a project's instructions, or add it to Claude as a skill.

Limits and privacy

  • The log is stored per site: a log recorded on example.com can only be viewed and exported from a page on example.com. Clear deletes it.
  • It keeps the newest 20,000 records and drops the oldest. AgentLog.start({ max: 50000 }) raises the cap.
  • It records from the moment it starts. Started from the bookmarklet, it misses whatever the page logged while loading; reload a page that includes the script with ?logging=true to catch that.
  • Query parameters with credential-like names (token, key, code, password, sig and similar) are replaced with REDACTED in recorded URLs. Request and response bodies and headers are not recorded. Console arguments are recorded as given, so read the export before you share it if the page logs anything private.
  • It covers the page itself: not its iframes, workers or service workers.

From the console, AgentLog.download(), AgentLog.copy(), AgentLog.export() (the OTLP object), AgentLog.stop() and AgentLog.clear() do what the panel's buttons do. The source is agent-log.js, one file with no dependencies.
