How it works

The page downloads a 4.9 MB model once, then runs it in tiles through ONNX Runtime Web, on WebGPU when the browser has it and on the CPU otherwise. The CPU path is slow: expect minutes for a megapixel. 2× and 3× are the 4× result scaled down.

Model: realesr-general-x4v3 from Real-ESRGAN (Wang et al., BSD-3-Clause), a small convolutional network trained on photos with noise and JPEG damage. It sharpens and removes compression artifacts, and it invents plausible texture, so treat fine detail as a guess.
