Web & File Utilities

PDF, OCR, CSV, photo and link tools that run in the browser

  • Anything to TextOCR for images and PDFs, speech-to-text for audio and video, in your browser
  • PDF to WebpageRebuild a PDF as a phone-readable page: reflowed text, tables, images, equations
  • SnapScan Photo ScannerScan printed photos: straighten, adjust color, set date and GPS, save a JPEG
  • AWS Region Latency MapMap of 32 AWS regions; click one for its median latency to the rest (May 2025 data)
  • Bookmarklet InstallerPick a bookmarklet from GitHub or paste JS, minify with Terser, drag to install
  • CSV to Excel ConverterDrop, pick or paste CSV, download .xlsx; converted in the browser with SheetJS
  • Gist EncryptionEncrypt text with AES-256-GCM in the browser; share as a gist, key in the URL fragment
  • HTML Trimmer for LLMsPaste HTML, untick elements or keep the first few repeated items and rows, then copy it
  • Image UpscalerEnlarge a photo 2x to 4x with Real-ESRGAN on WebGPU, nothing leaves your browser
  • OneNote Link ForwarderTurn a onenote: link into an https link that opens the OneNote desktop app
  • PDF CompressorShrink a PDF with Ghostscript compiled to WebAssembly, with four quality presets
  • PDF Reader and HighlighterAnnotate a PDF beside its extracted text: green or red marks, comments, JSON export
  • PDF Text ExtractorExtract PDF text as Markdown, JSON or plain text for LLMs, from a file or ?url= link
  • Webex Space ForwarderTurn a webexteams:// link or ?space=ID into an https link that opens the Webex app
  • WordCraftOpen-source Word-style editor in Rust, running in your browser as WebAssembly

Two more utilities

These two live elsewhere on the site and are not in the count above.

  • FileDropSend a file directly between two browsers, no server in the middle; connect by link or QR code
  • Acoustic LinkSend short data between two devices over sound, with only a speaker and a mic
