gPu(lemmings)

A Lemmings-style game written as WebGPU compute shaders. Every lemming state (walking, falling, building, bashing, mining, digging…) is its own small GPU kernel, run only over the lemmings in that state. The terrain is a GPU bitmap that bashers, miners, diggers and bombers carve. JavaScript writes the cursor and the chosen skill, and plays the sounds.

Not affiliated with the original 1991 game. The levels, art and sounds are made for this page.
