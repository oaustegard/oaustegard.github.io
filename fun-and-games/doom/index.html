DOOM ON THE GPU

The Doom engine rewritten as WebGPU compute shaders. One GPU thread per screen column walks the BSP tree and draws walls, floors and sprites; the game tic (movement, collision, doors, lifts, pickups) runs in GPU kernels too. JavaScript reads the WAD, passes keys and plays sounds.

Playing Freedoom's first episode (BSD licence). Monsters and weapons don't fight back yet: this build is the renderer and the world.
