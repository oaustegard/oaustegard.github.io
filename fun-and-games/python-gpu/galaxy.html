Python on the GPU · Fun & games

Two discs fall into each other. Every body pulls on every other: accel() is a Python function, compiled to a WebGPU compute shader with one invocation per body. Drag to pan, scroll or pinch to zoom.

Each substep runs accel() over every pair of bodies, then drift(). Colour is speed: blue slow, gold fast.

The Python is the source; the WGSL is what pykernel generated from it at build time. Drawing the points is a separate hand-written shader.
