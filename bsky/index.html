Bluesky Tools

Bluesky and ATProto pages: search, list builders, thread viewers, file transfer and blog-post widgets.

  • ATProto FileDropSend a file browser to browser over WebRTC, using Bluesky accounts to set up the connection
  • Bluesky Advanced SearchFill in author, domain, tag, date and language fields to build a bsky.app search URL
  • Post Constellation GraphGraph of a post's replies and quote chains that grows as you pan toward unexplored nodes
  • Anything to ListAdd accounts from a starter pack, list, feed, followers, post or search to a list
  • at-protocol ExtensionREADME of a Chrome extension that opens at:// URIs in bsky.app, rendered live from GitHub
  • Bluesky Engagement WidgetDemo and usage notes for a drop-in widget showing a post's replies, likes and reposts
  • Bluesky GitHub Link SearchSearch Bluesky posts from the last three days that link to github.com, with optional keywords
  • Bluesky Image ShowPlay the images from a thread, profile, feed, list or search as a slideshow
  • Bluesky Thread ViewerRead a thread as a branching tree, with filters, a quote-stack mode and shareable links
  • Bluesky ZeitgeistSamples the live firehose for trending names, then charts how often chosen topics appear
  • Engagement Data ProcessorExport a post's replies, quotes or ancestry, or search results, as anonymised JSON
  • Merge Bluesky ListsMerge another list into one of yours, adding only accounts not already on it
  • PadA plain-text pad in the browser, edited live with others over WebRTC, no server for the text
  • Post Constellation (Timeline)The constellation graph with posts placed left to right by time, with a toggleable time axis
  • Starter Pack to ListCopy every member of a starter pack into a new or existing list of yours
  • Tangled String EmbedDemo of a script that embeds a Tangled string in any page; it embeds its own source
  • Tangled StringsView Tangled strings (snippets stored in ATProto repos) by handle/rkey, at:// URI or URL
  • The Bsky ReportMost-shared links on Bluesky over 24 hours, built by polling post search per language
