AI & LLM Tools

Claude log viewers, a skill packager, LLM price tables and small model demos

  • KB PackerTurn files into a searchable .skill bundle an AI agent can install, in the browser
  • LiteLLM Model PricesSortable, filterable LLM prices and context windows, live from LiteLLM's data
  • Shell Doc SearchDescribe a task in plain words, get the command-line tool, from 6,397 doc pages
  • cc-inspectPython script: Claude Code session logs to a markdown report, no LLM calls by default
  • Claude API Response ViewerView a Claude API response saved in a gist: thinking, web searches, cited text
  • Claude Audit Log ViewerOpen a Claude Enterprise audit-log zip: stats, filters, search, CSV export
  • Claude PrunerKeep only the messages, artifacts and tool calls you pick from a Claude.ai chat
  • Claude Skills ReleasesEvery release of claude-skills, sortable A-Z or by date, with zip downloads
  • Cross-Origin Fetch ProbeCheck whether a page on this site can fetch a URL with GET, HEAD and Range requests
  • Embedding InversionBrowse 1,000 recorded attempts to recover a sentence from its embedding, round by round
  • Latent CalculatorSmolLM2-135M does arithmetic three ways, one with a calculator wired into its layers
  • Repo SearchSearch 3,510 posts, blog entries, issues and bookmarks from two AT Protocol accounts
  • Research Report ViewerOpen a JSON research report: sections, TLDRs, citations; export as HTML or Markdown
  • Taxonomy SnapType a product phrase, get the nearest of 860 retail categories, in the browser
  • Token Salary CalculatorCompares the cost of N tasks a day in salaries and in AI tokens, in five scenarios
