Page Scrawl

Draw on any web page and type a note on each mark. Every mark is tied to the element under it: its selector, text and styles, plus the component and source file on development builds. Claude can read the marks and fix the page, or you can paste them into any chat.

Bookmarklet

Drag this link to your bookmarks bar:

✎ Scrawlloading the script…

Clicking it here works as a demo. The script is overlay.js from the marking-up-pages-v0.2.0 tag of oaustegard/claude-skills, fetched when this page loads, so the link always matches that release.

Using it

  1. Click the bookmarklet on the page you want to mark up, then circle, underline, point at or cross out what is wrong.
  2. A note box opens after each mark. Type or dictate what should change, then press Enter.
  3. ⌥⇧S turns drawing off so you can click around the page, and on again to keep marking.
  4. Press Done. With Claude in Chrome on that tab, tell Claude to look at your marks. Otherwise Copy puts the marks on the clipboard as text and Save downloads a .scrawl.json file, to paste or attach in any chat.

Marks stay in the tab until you reload it. Sites with a strict Content-Security-Policy may block bookmarklets.

The Claude skill

The marking-up-pages skill lets Claude in Chrome open the overlay itself, read the marks, find the source for each one and make the changes, or write up the edits when the site is someone else's. Download marking-up-pages.zip from the v0.2.0 release and upload it under Customize, Skills in Claude.ai.
